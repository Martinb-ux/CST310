Topic 10 - Advanced Shading Techniques Project
===============================================

This project implements three advanced shading techniques on 3D objects using modern OpenGL: Environment Mapping, Parallax Mapping, and Bump Mapping.

SCENE OBJECTS WITH ADVANCED SHADING:
-----------------------------------
1. Checkerboard Floor - 8x8 grid with alternating purple and white tiles (basic lighting)
2. Cube with Environment Mapping - Central cube with reflective Yokohama2 cube mapping
3. Cylinder with Bump Mapping - OBJ model with surface detail using normal maps
4. Sphere with Parallax Mapping - OBJ model with depth illusion using height maps

CAMERA CONTROLS (Mac):
---------------------
Movement:
- Right Arrow: Slide camera +X (right)
- Left Arrow: Slide camera -X (left)
- Up Arrow: Slide camera +Y (up)
- Down Arrow: Slide camera -Y (down)
- Shift + Up Arrow: Slide camera "out" (negative Z)
- Shift + Down Arrow: Slide camera "in" (positive Z)

Rotation:
- Command + Up Arrow: Pitch -2 degrees
- Command + Down Arrow: Pitch +2 degrees
- Command + Right Arrow: Yaw +2 degrees
- Command + Left Arrow: Yaw -2 degrees
- Shift + Comma (<): Roll +2 degrees
- Shift + Period (>): Roll -2 degrees

Other:
- R: Reset camera to origin
- ESC: Exit application

SOFTWARE REQUIREMENTS:
---------------------
macOS with Homebrew installed

Required Libraries:
- GLFW (Window management)
- GLEW (OpenGL extension loading)
- Assimp (3D model loading)
- GLM (Mathematics library)
- stb_image (Image loading - included)

INSTALLATION:
-------------
Install dependencies via Homebrew:
brew install glfw glew assimp glm

COMPILATION:
-------------
Using Makefile (Recommended):
make          # Build the project
make execute  # Build and run

Manual Compilation:
g++ main.cpp -o run -L/opt/homebrew/lib -lglfw3 -framework OpenGL -framework Cocoa -framework IOKit -framework CoreVideo -lGLEW -lassimp

RUNNING:
-------
./run

FILES:
------
main.cpp          - Main application with rendering loop and camera controls
Camera.h          - Camera class with movement and rotation
Model.h           - 3D model loading class (uses stb_image)
Mesh.h            - Mesh rendering class
shader.h          - Shader program wrapper
stb_image.h       - Image loading library
*.vs, *.frag      - Vertex and fragment shaders
*.obj, *.mtl      - 3D model files
Makefile          - Build configuration
README.md         - Detailed documentation

KEY FEATURES:
-------------
- Modern OpenGL 3.3 Core Profile
- Environment Mapping (Cube Mapping) for reflective surfaces
- Parallax Occlusion Mapping for depth illusion
- Bump Mapping using normal maps for surface detail
- OBJ model loading with Assimp
- Advanced lighting with tangent space calculations
- Interactive camera with full 6DOF movement
- Cross-platform compatible (Mac optimized)
- Clean, commented code structure

TROUBLESHOOTING:
---------------
- Ensure all Homebrew libraries are installed
- Check that Xcode Command Line Tools are installed
- Verify OBJ and MTL files are present in the same directory
- Make sure OpenGL 3.3+ is supported by your system

PROJECT STRUCTURE:
-----------------
The scene is arranged as:
- Cube (Environment Mapping): Center (0.0, 0.0, -5.0)
- Cylinder (Bump Mapping): Left (-1.8, -3.0, -5.5) 
- Sphere (Parallax Mapping): Right (1.2, 0.0, -5.0)
- Checkerboard: 8x8 grid from (-4, -9) to (4, -1)

TEXTURES USED:
--------------
- Yokohama2/ cube map: Environment mapping for cube
- Bump-Picture.jpg: Diffuse texture for sphere and cylinder
- Bump-Map.jpg: Height map (sphere) and normal map (cylinder)

All objects are rendered with advanced shading techniques and can be viewed from any angle using the camera controls.
